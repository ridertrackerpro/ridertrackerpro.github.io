⚠️ Permessi Importanti
Per garantire il funzionamento del GPS anche con l'app in background, segui questi passaggi nelle impostazioni del telefono.
📍 Posizione
Impostazioni → App → RiderTracker Pro → Autorizzazioni → Posizione → Consenti sempre
🔋 Batteria
Impostazioni → App → RiderTracker Pro → Batteria → Senza restrizioni
📡 Dati in background
Impostazioni → App → RiderTracker Pro → Connessione dati → Attiva tutto
🛡️ Gestione app non utilizzate
Impostazioni → App → RiderTracker Pro → Disattiva "Gestisci app non utilizzate" se attivo
